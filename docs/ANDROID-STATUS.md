## Ранее доставленные изменения 0.7

- Три настраиваемых сайта проверки **наличия БС**: готовые варианты без клавиатуры, собственный домен через карандаш; первые два — напрямую, третий — через VPN.
- Обновление списка после добавления сервера, компактное добавление движка.
- Компактный вход VK, отступы и две нижние кнопки рядом; системный возврат Android; для связанного аккаунта — только отвязка. Успешный внешний вход VK после провайдерской ошибки не считается доказанным только по этим исправлениям.
- Опубликованные дополнительные протоколы, DNS-туннели и обновления модулей. Полный перечень и отдельные версии CSQTT/SWG находятся в руководстве.

## Доработки после review Steer

Источник: review PR splify2/steer [#11](https://github.com/splify2/steer/pull/11)–[#27](https://github.com/splify2/steer/pull/27). Замечания относятся к предложенному upstream-коду и требуют сверки с текущей веткой MCRF; наличие дефектов в текущем приложении не подтверждено. Оценки сложности и статусы — в [подтаблице Android-пула](../README.md#доработки-после-review-steer).

Последовательность: П0 — аудит двойного close fd → socket-prepare/protect вспомогательных сетевых путей; П1 — DNS TTL/CNAME и очистка synthetic IPv6 → фиксированные лимиты и очереди proxy → негативные тесты DNS/.srs/regex/handshake; П2 — событийное ожидание вместо polling → C/JNI API для reuse DNS/.srs matching; П3 — TCP для host-owned TUN.

## Объективные ограничения

CSQTT 2.5: в первоначальном каталоге 0.7 был только APK ARM64 (модуль 6), несмотря на три скомпилированные нативные пары. После публикации 0.7.1 исправлен фильтр упаковщика и отдельно опубликован модуль 7 для трёх архитектур и универсальный APK. Поддержка упаковки завершена; новые реальные сессии на ARMv7/x86_64 не проверялись.

Не закрыты все живые сценарии VK/MASQUE/CAPTCHA, серверные реализации SSTP/MasterDnsVPN/OLCRTC/DNSTT, все пары CSQTT/форков и физические устройства других ABI. Для OpenFlux не заявляется принятие экспериментальных ownHTTP/inline/script-сценариев. Полный процент ревью по числу успешных unit-тестов не вычисляется: реализация, сборка, локальная передача и приёмка внешнего провайдера — разные уровни доказательств.

Выпуск 0.7 сохранён без замены его APK. Приложение 0.7.1 и OpenFlux 0.16 опубликованы раздельно; соответствующие исходники и контрольные суммы приложены к выпуску приложения и каталогу движков.
