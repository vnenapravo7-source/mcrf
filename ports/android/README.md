# MCRF Android

Android 10+ · релиз [0.6](https://github.com/vnenapravo7-source/mcrf/releases/tag/android-v0.6), build 10043.

[Обзор интерфейса и возможностей](../../docs/ANDROID-GUIDE.md) · [План по приоритетам](../../README.md#пул-реализации-android)

Основное приложение не содержит native-движков и выпускается одним универсальным APK. sing-box, Steer, компактный WG/AWG и дополнительные транспорты устанавливаются отдельно из [единого каталога](https://github.com/vnenapravo7-source/mcrf/releases/tag/engines-2026-10-13-1). Для Steer нет armeabi-v7a; CSQTT 2.5 пока только arm64.

Выпуск добавляет правила, DNS, авторизованные локальные HTTP/SOCKS5 и IPv6 для Steer; компактный WG/AWG 3.0/3.1 с IP-правилами, блокировкой и DNS.

П2 включён в 0.6: отдельные серверы и группы по правилам, DNS и прямой выход, остановка движков, автовыбор и WARP; три группы маршрутов, расширенный Vk Turn, поколения CSQTT 2.0 / 2.1.5 / 2.1.9 / 2.5, автодеплой и управление панелями. SWG Panel — 1.8.10-beta. Интервалы счётчиков уведомления настраиваются, при выключенном экране опрос остановлен; счётчики можно отключить полностью.

## Исходники и сборка

Исходники в репозитории соответствуют тегу выпуска. Полные зафиксированные входы и соответствующие исходники native-модулей также приложены ZIP-архивами к пререлизу; контрольные суммы — SHA256SUMS.txt. Не подменяйте их текущими upstream-версиями.

Требуются JDK 17, Android SDK 34, build-tools 36.0.0 и Gradle wrapper. Предварительно собранные compile-only/runtime AAR и закреплённые зависимости находятся в исходном архиве выпуска; они не включаются в основной APK как native-библиотеки. Локальный путь SDK задаётся через ANDROID_HOME или local.properties, который не публикуется.

Из каталога ports/android:
```powershell
./gradlew.bat :app:assembleRelease -PtestRelease=true
```

Флаг testRelease явно использует подпись разработки. Публичные APK сохраняют существующую тестовую подпись для обновления поверх предыдущих версий. Не удаляйте приложение перед обновлением: его данные защищены Android Keystore.

Релизный код минимизируется R8. Новые/изменённые проверки выполняются общим пакетом, уже закрытые неизменённые сценарии не прогоняются заново после каждой правки. Область подтверждённых проверок и ограничения описаны в BUILD_EVIDENCE.json выпуска.
