# Доработки текущего MCRF

## Редактор стратегий

1. Откройте Zapret → Редактор стратегий. Выберите основу, например ALT8, и имя копии, например ALT8 fork.
2. Выберите блок. Предпросмотр показывает его аргументы отдельными строками, сохраняя порядок.
3. В списке аргументов ✓ означает, что аргумент уже присутствует, ○ — что отсутствует. Переключатель наличия добавляет/удаляет аргумент; кнопки позволяют явно применить значение или удалить его целиком.
4. Готовый вариант сопровождается пояснением. Поле ввода показывается только при выборе «Ввести значение вручную». Для файлов поддельных пакетов можно выбрать настоящий BIN из папки движка.
5. «Редактировать конфиг BAT целиком» позволяет вставить конфиг с переменными и продолжениями строк. BAT не исполняется: импортируется конфигурация движка. Неопределённые переменные и неподдержанные аргументы отклоняются, область применения задаётся маршрутом.
6. «Сохранить копию» создаёт отдельную стратегию в общем каталоге. Основа и активные маршруты не меняются. Для использования копии нужно выбрать её в нужном профиле/маршруте.
7. «Проверить копию» запускает проверку выбранных сервисов. Наличие сохранённой копии само по себе не означает, что она работает.
8. «Отмена» возвращает в Zapret без сохранения текущего черновика. Уже сохранённые копии не удаляются.

При возврате из BAT в конструктор блоки перечитываются. Некорректный BAT нельзя незаметно заменить устаревшими значениями конструктора.

## Генератор стратегий: не случайный подбор

1. Пользователь выбирает сервисы, имя, профиль и бюджет — до 12 или до 24 проверок.
2. Проверяются 6 или 8 начальных вариантов разных основ на текущем подключении.
3. Приоритет: доступность выбранных сервисов, успешные запросы, затем время ответа. Быстрый вариант с ошибками не становится победителем.
4. У двух удачных основ меняется по одному параметру: число повторов, порог прекращения подмены, при подходящей основе позиция разбиения/TTL. Повторяющиеся конфигурации исключаются.
5. Если ни одна основа не подтвердила сервисы, слепой перебор прекращается.
6. Лучшие варианты проверяются ещё дважды. Рекомендация для сервиса требует минимум трёх успешных проверок одного варианта.
7. Сохраняются подтверждённые варианты и результаты; применение требует действия пользователя. Отмена сохраняет завершённые проверки.

Это ограниченный измеряемый поиск, не гарантия самого лучшего варианта из всех возможных. Проверки интерфейсов сервисов не подтверждают голосовой чат и игровые матчи.

## Интерфейс и размер

- Кнопки маршрутов расположены двумя рядами в запрошенном порядке; добавлена кнопка изменения.
- В редакторе маршрута увеличено основное поле, выровнены отступы, условие, пресеты и нижние действия.
- Удалены подсказки при наведении в обновлениях, уменьшено пустое место; обновление отображения ограничено изменением данных.
- Исправлены прямоугольные углы кнопок горячих клавиш и устаревший фон после изменения размера. Двойной щелчок по верхней рамке разворачивает/возвращает окно.
- В расширенном интерфейсе главная содержит две колонки без прокрутки; переключатели модулей находятся внизу боковой панели.
- Подготовка пресетов маршрутов выполняется вне UI-потока. Перерисовка боковых переключателей не заставляет каждую секунду обновлять всё окно.
- Три дополнительных движка не встроены. Пресеты сжимаются без потери содержимого. Локальная сборка — около 51,4 МиБ. Основные сетевые компоненты остаются встроенными.
- Редактор: параметры слева, постоянно видимый текущий блок справа, отдельный режим BAT. Наличие аргументов отмечается ✓/○; ручной ввод появляется только при ручном выборе.
- Удалена покадровая полноэкранная bitmap-анимация переходов. Окна открываются сразу; при живом изменении размера базового экрана показывается сохранённый кадр, затем окончательная разметка.
- Фон содержит статичный малоконтрастный узор из сетевых значков. Один прозрачный тайл 420×300 повторяется без генерации полноэкранных картинок и анимации; WPF использует тот же узор.

## Что не подтверждено

Конфигурационные проверки подтверждают, что WARP не присваивает chess.com и не подменяет общий DNS автоматически. Они не доказывают, что сайт открывается на проблемном подключении. Исправление этой конкретной проблемы не подтверждено.

Оригинальный движок и движок MCRF имеют отдельные области перехвата. Проверено построение конфигураций и отсутствие параметров процесса в оригинальной части. В текущем окружении запуск оригинального EXE с административными правами не проверен. Визуальные проверки не гарантируют отсутствия всех артефактов на любой видеокарте/DPI.
