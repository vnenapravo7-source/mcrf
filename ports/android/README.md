# MCRF Android

Android 10+ · целевой выпуск [2.0](https://github.com/vnenapravo7-source/mcrf/releases/tag/android-v2.0), build 10065. Pipeline подготовлен; сборка и публикация этой ветки ещё не выполнялись.

[Обзор интерфейса и возможностей](../../docs/ANDROID-GUIDE.md) · [План по приоритетам](../../README.md#пул-реализации-android)

В текущей ветке добавляется привязка по шестизначному инвайт-коду: Wi-Fi-подписка и четыре типа подключений по три сервера (WDTT, QWDTT, CSQTT SWG 2.1.9 и CSQTT SWG 2.5.1) синхронизируются по общему расписанию подписок. Серверный контракт описан в [docs/ANDROID-INVITE-CODE.md](docs/ANDROID-INVITE-CODE.md).

Основное приложение не содержит native-движков: sing-box, Steer, компактный WG/AWG и дополнительные транспорты устанавливаются отдельными APK. Финальный pipeline выдаёт APK приложения для arm64-v8a, armeabi-v7a и x86_64; для Steer нет armeabi-v7a.

Выпуск 2.0 добавляет автоматический выбор поколения CSQTT, выбор загрузки одного или всех движков и общие карточки серверов VPN/БС. Сохранены CSQTT 2.0/2.1.5/2.1.9, добавлены входы SWG 2.5.1/2.5.2/2.5.3. Автоматический режим требует все четыре пакета: `csqtt20`, `csqtt215`, `csqtt` (2.1.9), `csqtt25`.

Также восстановлена работа TURN без пользовательских правил, выбран VPN/прокси для основного трафика по умолчанию, показаны фактические потоки и IP TURN-сервера, скрыт неактивный прокси в уведомлении. Добавлено случайное оформление при каждом возврате в приложение; обновлены QWDTT, WDTT, CSQTT и Steer. Контракт финальной упаковки и статическая проверка: [maintenance/Release08.md](maintenance/Release08.md).

## Исходники и сборка

Финальная упаковка привязывает исходники к точному снимку сборки и архиву `mcrf-android-2.0-source.zip`; метаданные каталога — `mcrf-android-2.0-engines.json`, контрольные суммы — SHA256SUMS.txt. Публикация выполняется отдельным этапом после приёмки. Зафиксированные native-входы нельзя подменять текущими upstream-версиями.

Требуются JDK 17, Android SDK 34, build-tools 36.0.0 и Gradle wrapper. Предварительно собранные compile-only/runtime AAR и закреплённые зависимости находятся в исходном архиве выпуска; они не включаются в основной APK как native-библиотеки. Локальный путь SDK задаётся через ANDROID_HOME или local.properties, который не публикуется.

Из каталога ports/android:
```powershell
./gradlew.bat :app:assembleRelease -PtestRelease=true
```

Флаг testRelease явно использует подпись разработки. Публичные APK сохраняют существующую тестовую подпись для обновления поверх предыдущих версий. Не удаляйте приложение перед обновлением: его данные защищены Android Keystore.

Релизный код минимизируется R8. Новые/изменённые проверки выполняются общим пакетом, уже закрытые неизменённые сценарии не прогоняются заново после каждой правки. Область подтверждённых проверок и ограничения описаны в BUILD_EVIDENCE.json выпуска.
