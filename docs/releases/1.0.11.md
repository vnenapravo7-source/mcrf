# MCRF 1.0.11 · Windows x64

Предрелиз нового единого WPF-интерфейса; опубликован по запросу владельца после ознакомления с результатом VirusTotal. Пользователю нужен один `mcrf.exe`; основные ресурсы распаковываются при необходимости, дополнительные OpenFlux/CSQTT/WDTT/QWDTT скачиваются из приложения с GitHub после проверки SHA-256.

**Предупреждение:** для опубликованного EXE на предоставленном скриншоте VirusTotal показаны **4/70 срабатывания**, включая Kaspersky. Их причины и ложноположительность не подтверждены. Этот предрелиз не обозначается как полностью проверенный или гарантированно безопасный.

## Что изменилось

- Новый логотип и значки окна, EXE и трея.
- Исправлены обрезанные обводки кнопок, отступы и компоновка при небольшом размере окна. Галочки TCP/UDP больше не пересоздают страницу маршрутизации.
- Редактор стратегий: одна горизонтальная лента с прокруткой мышью, крестики удаления разделов, пояснения при наведении и нажатии «i», таблица «название — значение — пояснение».
- Автовыбор: период по умолчанию 60 секунд, допустимое отклонение 50 мс; при выключенном автовыборе период скрыт.
- Уплотнены поля автодеплоя, выровнены строки и добавлена общая прокрутка. Готовые подключения показаны отдельным блоком; попап содержит ссылку импорта, ключ/UUID и QR. Последний результат защищён DPAPI для текущего пользователя Windows.
- 3x-ui: автоматическое создание VLESS TCP/gRPC REALITY. Для новых TCP-профилей выбран совместимый с современным REALITY отпечаток Chrome.
- OpenFlux: выбор носителя, автоматический ключ шифрования, готовая ссылка и QR. Go и кэш сборки размещаются отдельно в каталоге OpenFlux, без замены системного Go.
- SWG: CSQTT/WDTT/QWDTT, кнопка создания шести звонков VK. Сначала вход на главной vk.ru, затем получение токена в той же сессии. Ручные ссылки используются без авторизации; вставка нескольких ссылок создаёт отдельные поля, плюс добавляет ещё одно поле.
- QWDTT доступен как дополнительный движок; в основной EXE его бинарный файл не встроен.

## Проверено

- Локальные проверки интерфейса, границ обводок и выравнивания: 3687 проверок; TCP/UDP без замены окна/таблицы: 160 проверок.
- Ключи, попапы, QR, ручные VK-ссылки и защищённое сохранение результатов: 79 проверок; семь QR независимо декодированы в исходные ссылки.
- 28 контролируемых API/протокольных тестов и 62 проверки интеграции; это не заменяет реального подключения к внешнему сервису.
- Один полный локальный функциональный прогон прошёл 165 проверок; 141 проверка логотипа и значков прошла на финальном кандидате.
- TUN и ограниченный WinDivert совместно с остальными движками: 36 проверок с повышением прав. Тестовые адаптер и служба удалены; пользовательские адаптеры сохранены.
- На разрешённом тестовом сервере оба созданных TCP/gRPC-профиля и зашифрованный OpenFlux Direct передали HTTPS через Windows-клиент. Для OpenFlux проверены действительный ключ, ссылка и QR. Тестовые установки удалены.
- Вход VK и получение токена подтверждены пользователем.

## Ограничения предрелиза

- Удалённый трафик SWG/CSQTT/WDTT/QWDTT, создание шести настоящих VK-звонков и внешние носители OpenFlux, кроме Direct, ещё требуют живой проверки.
- Доступность WARP, видео, голоса и игровых сервисов зависит от сети; успешный локальный тест не гарантирует работу у каждого провайдера.
- Автодеплой предназначен для Debian/Ubuntu с root или sudo без пароля. Он изменяет серверные пакеты/службы; автоматического отката всей установки нет. Существующая панель не перезаписывается.
- Новый интерфейс использует отдельный профиль `%LOCALAPPDATA%\mcrf-wpf`; старый профиль не переносится автоматически. Перед запуском закройте другой MCRF.
- Нужны Windows x64 и .NET Framework 4.8; вход VK использует установленный WebView2 Runtime. TUN, Zapret и изменение системного hosts требуют прав администратора.
- Linux/CachyOS, Android APK и iOS IPA ещё не выпускаются.

Поскольку это предрелиз, обычное обновление со стабильной версии не устанавливает его автоматически. Скачайте `mcrf.exe` вручную и сверьте `SHA256SUMS.txt`. Данный EXE не подписан сертификатом Authenticode. [Отчёт VirusTotal, предоставленный пользователем для финального файла](https://www.virustotal.com/gui/file-analysis/Y2YyNzAwMGMwZWE1Yjc3OTkyYzkyYWQ1ZTkzN2I4MzE6MTc5MTkxNDYxMw==): идентификатор ссылки совпадает с MD5 `cf27000c0ea5b77992c92ad5e937b831`. На предоставленном скриншоте отчёта для SHA-256 `df10c79cc30fb19dfeb1b60b2ea9316961756889d6520d5aae5fabd23cea7fb7` показаны 4/70: Kaspersky `HEUR:Trojan-Dropper.MSIL.Agent.gen`, McAfee Scanner `Ti!DF10C79CC30F`, SecureAge `Malicious`, Trapmine `Malicious.moderate.ml.score`. Живой отчёт через инструменты не загрузился. Причина срабатываний и их ложноположительность не подтверждены; предупреждение сохранено при публикации по запросу владельца. Статическая инвентаризация 27 бинарных/архивных ресурсов прошла: все 24 сжатых бинарных ресурса совпадают с кэшированными входами сборки, три несжатых ресурса учтены отдельно. Это не антивирусный вердикт и не независимое доказательство безопасности.
