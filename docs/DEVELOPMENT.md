# Исходники MCRF

## Структура

| Каталог | Содержимое |
| --- | --- |
| `wpf/` | Текущий Windows-интерфейс, автодеплой, VK и выдача подключений |
| `native/` | Модель профиля, маршруты, сетевые движки, сохранение и общий код |
| `native/assets/` | Логотип, оформление, стратегии, пресеты и каталог дополнительных движков |
| `native/zapret-engine/` | Расширение Zapret для приложений, патч и сборка |
| `native/turn-engines/` | Мост CSQTT и сборка дополнительных движков |
| `tests/`, `native/tests/`, `wpf/tests/` | Проверки общего кода и интерфейса |
| `docs/screenshots/` | Скриншоты текущего интерфейса |
| `docs/releases/` | Список изменений релиза |

Часть исходников прежнего интерфейса сохраняется в `native/`: они входят в общую сборку или используются тестами.

## Сборка

[Зависимости и команды сборки](BUILD.md). Основной файл — `mcrf.exe`; ресурсы и управляемые библиотеки встроены в него. Версии приложения задаются в `native/AssemblyInfo.cs`.

Встроенные компоненты: sing-box-lx, ByeDPI, Telegram WS, WarpScout, curl, WebView2 SDK, SSH.NET, QRCoder, Flowseal и расширение Zapret. Дополнительные OpenFlux/CSQTT/WDTT/QWDTT перечислены в `native/assets/optional-engines.json` и скачиваются отдельно.

## Профиль и процессы

`ClientSession` соединяет интерфейс с моделью `ClientState`. Изменения проходят через `ChangeConfiguration`; сетевые операции и проверки выполняются в фоне.

Конфигурации выходов собирает `NetworkCore`, правила — `RouteCompiler`, профили Zapret — `ZapretRoutes`. Запущенные приложением дочерние процессы принадлежат `OwnedJob`.

Профиль текущего интерфейса хранится в `%LOCALAPPDATA%\mcrf-wpf`. Результаты автодеплоя защищены DPAPI текущего пользователя Windows; SSH-пароль и VK-токен в них не сохраняются.

## Проверки и публикация

Локальные наборы находятся в `tests/`, `native/tests/` и `wpf/tests/`. `ReleaseScreenshots20261013.cs` создаёт снимки с демонстрационными данными, не подключаясь к серверу. `EmbeddedInventoryCheck20261013.cs` сверяет встроенные бинарные ресурсы с входами сборки.

В публичные исходники не входят профили, пароли, журналы и служебные сценарии тестового сервера. Лицензии компонентов сохранены рядом с соответствующими исходниками и встроенными ресурсами.

После публикации и проверки релиза локальные артефакты очищаются по [AGENTS.md](../AGENTS.md) скриптом `native/cleanup-artifacts.ps1`.
