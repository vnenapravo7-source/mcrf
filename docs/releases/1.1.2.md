## Что изменилось с 1.1.1

- Исправлена обработка DNS, Fake-IP и IPv6 в TUN с CSQTT, включая маршруты «РФ — напрямую».
- Исправлены сбросы соединений при загрузке сайтов и видео через локальный IP-адаптер.
- При подключении сохранённого сервера приложение предлагает докачать недостающий IP-адаптер.
- В маршрутизации явно отображается исключение РФ у пресета «Всё кроме РФ».

С 1.1.1 обновление устанавливается из раздела «Обновления»: малый пакет приложения и обновлённое сетевое ядро, без повторной загрузки остальных неизменившихся компонентов. `mcrf.exe` — полная сборка для первой установки.
