# MCRF Windows 1.2

- Обновлены настройки, таблица маршрутов и редакторы серверов и правил.
- DNS и Game сохраняют изменения автоматически; окна выбора пресетов и приложений стали просторнее.
- Исправлены мигание при закрытии редактора, отступы и оформление элементов управления.
- Добавлена поддержка OpenFlux 0.16 и FluxFast.
- Для моста CSQTT включён MTU 1400 с фрагментацией и обратной сборкой крупных пакетов.
- Ускорена отрисовка списка VPN; проверка автозапуска больше не задерживает первый экран.

Полная сборка: [mcrf.exe](https://github.com/vnenapravo7-source/mcrf/releases/download/v1.2/mcrf.exe).
Обновление из приложения использует малый пакет и только необходимые компоненты.
