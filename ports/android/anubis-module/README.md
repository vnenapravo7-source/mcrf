# Пакет Anubis для Android 2.0.1

Модуль `org.mcrf.anubis` использует одну сборку для всех архитектур. Он получает события окон через системную службу специальных возможностей. Основной APK хранит правила и применяет их. Служба и описание внесены в манифест модуля. В манифесте MCRF остаются только защищённые подписью компоненты обмена.

1. Собрать `:anubis-module:assembleRelease`. Подписать модуль тем же сертификатом, которым подписан основной APK и релиз 2.0.0. Сверить сертификаты обеих подписанных сборок через `apksigner verify --print-certs`.
2. После приёмки приложить модуль к релизу `android-v2.0.1` под именем `mcrf-anubis-release.apk`. Это имя и тег использует кнопка скачивания.
3. Проверить на устройстве с Play Защитой. Установить основной APK из браузера, затем проверить чистую установку, установку поверх 2.0 и опциональную установку модуля. Проверить запрет правил до выдачи разрешения, сохранение старых правил и работу при отзыве разрешения.
4. Прогнать открытие и закрытие тестовых приложений с VPN и без VPN, включая открытие с рабочего стола и остановку VPN после выхода. Проверить удаление и повторную установку модуля.

Разрешение старой встроенной службы Android не переносит между компонентами. Для установки поверх 2.0 приложение показывает одно действие восстановления вместо отдельного блока скачивания.
