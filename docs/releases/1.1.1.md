## Что изменилось с 1.1

- В TUN трафик без совпавшего правила идёт через выбранный VPN. Явные правила и исключения сохраняют приоритет.
- Добавлен готовый пресет «Всё кроме РФ» в маршрутизацию и конструктор: РФ — напрямую, остальное — через VPN.
- Добавлены встроенные малые обновления приложения. Код устанавливается небольшим пакетом; неизменившиеся движки повторно не скачиваются.

Для перехода с 1.1 один раз скачайте обычный `mcrf.exe` и замените старый файл. Настройки сохранятся. Начиная с 1.1.1 дальнейшие обновления устанавливаются из раздела «Обновления», без отдельного установщика или патчера.
