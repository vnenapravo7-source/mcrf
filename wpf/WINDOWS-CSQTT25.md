# MCRF Windows: CSQTT 2.5 и автодеплой

Ссылки CSQTT 2.5 из SWG Panel импортируются без преобразования пользователем.
Для них используется отдельный `csqtt25-client.exe`; старые открытые ссылки
`csqtt://connect?...` по-прежнему запускают CSQTT 2.1. Переключения между
несовместимыми версиями при ошибке подключения нет.

Обе версии входят в один дополнительный модуль CSQTT, загружаемый по требованию:
[Windows amd64, около 17,2 МБ](https://github.com/vnenapravo7-source/mcrf/releases/download/engines-2026-10-13-1/mcrf-csqtt25-windows-amd64.zip).
Модуль не вшит в основной EXE. Существующие подключения и другие движки сохраняются.

В «Автодеплой» выберите SWG → CSQTT 2.1 или CSQTT 2.5 и создание подключения
после установки. Для 2.5 можно вставить до шести своих звонков VK; вход VK для
готовых ссылок не нужен. SWG устанавливается из закреплённого исходного кода.
Создаётся именно выбранная серверная ветка, а результат выдаётся после подтверждения версии запущенного
сервера и нового пароля в его состоянии. Готовая ссылка формата CSQTT 2.5
попадает в обычные данные подключения: импорт, просмотр реквизитов, QR и обмен.
Существующая SWG-установка автоматически не перезаписывается.

Раздел «Автодеплой» хранит несколько панелей и их серверы. Сохранённую панель
можно выбрать после перехода между разделами или перезапуска программы,
открыть в браузере, проверить и переименовать. Новые подключения создаются
через API без повторной установки панели; старые ссылки сохраняются.
Один протокол можно добавлять несколько раз и задавать каждому своё название.
Занятые порты проверяются по панели и серверу; для нового туннеля подбираются
свободные порты и отдельная подсеть. Реквизиты панелей и ссылки хранятся
зашифрованными; SSH-пароли не сохраняются.

Автодеплой WDTT и QWDTT также выдаёт готовые ссылки подключения. В запуске
QWDTT исправлен локальный UDP-порт: WireGuard получает реальный порт, а не `0`.

Драйверная служба Zapret теперь регистрируется как `MRCF_WD` (написание по ТЗ).
Подписанный `WinDivert64.sys` и внутреннее устройство `\\.\WinDivert` не меняются.
Уже загруженный совместимый драйвер другого приложения может использоваться
повторно по исходной логике WinDivert; чужие службы не удаляются и не останавливаются.
Изменение имени службы не делает драйвер невидимым для античита.

Исходники и лицензии дополнительных компонентов:
[CSQTT](https://github.com/vnenapravo7-source/mcrf/releases/download/engines-2026-10-13-1/mcrf-csqtt25-windows-source.zip),
[изменённая DLL WinDivert](https://github.com/vnenapravo7-source/mcrf/releases/download/engines-2026-10-13-1/mcrf-windivert-mrcf-wd-source.zip).
